# Visit Your City's Future Climate

Геопортал **климатических аналогов**. Для каждого из 517 крупных городов он находит город, чей *сегодняшний* климат больше всего похож на климат этого города через 30–50 лет.

Интерфейс карты на английском языке.

## Как это работает

**Метод: климатические аналоги и многомерный анализ.**

1. Для центров городов берутся 19 биоклиматических переменных WorldClim (BIO1–BIO19).
2. Переменные стандартизируются, по сегодняшнему климату строится PCA. Сохраняются главные компоненты, на которые приходится не меньше 85 % дисперсии.
3. Будущий климат проецируется в те же компоненты.
4. Для каждой пары «будущий город — сегодняшний город» считается евклидово расстояние в пространстве компонент. Ближайший сегодняшний город — климатический аналог.
5. «Новый климат»: будущая точка лежит вне выпуклой оболочки всех сегодняшних городов (проверка через линейное программирование).

### Сценарии

| Сценарий | Горизонт | Данные | Статус |
|---|---|---|---|
| `bastin2019_rcp45_2050` | ≈2050, RCP4.5 | Bastin et al. 2019, PLOS ONE (CC BY 4.0) | уже в репозитории |
| `cmip6_ssp245_2041-2060`, `cmip6_ssp585_2041-2060` | ≈2050 | WorldClim 2.1 CMIP6, ансамбль 6 моделей | собирается через GitHub Actions |
| `cmip6_ssp245_2061-2080`, `cmip6_ssp585_2061-2080` | ≈2070 (≈45 лет вперёд) | WorldClim 2.1 CMIP6 | собирается через GitHub Actions |

Матрица расстояний 517 × 514 из Bastin et al. (2019) в точности евклидова в 4-мерном пространстве. Скрипт `pipeline/build_bastin.py` восстанавливает координаты городов в пространстве ГК1–ГК4 методом многомерного развёртывания (multidimensional unfolding). Ошибка 3·10⁻⁵ при данных, округлённых до 10⁻⁴. Проверка воспроизводит результаты статьи:

- доли дисперсии осей 47,7 / 31,2 / 12,3 / 8,9 % совпадают с 40,2 / 26,9 / 10,5 / 7,6 % из статьи после нормировки на сумму четырёх компонент;
- новый климат у 22,2 % городов (в статье 22 %);
- у 76 % городов ближайший аналог — другой город (в статье 77 %).


### Добавить горизонты 30–50 лет (CMIP6)

**Actions → Build CMIP6 analogues → Run workflow.** Workflow скачивает растры WorldClim 2.1 (10′, около 1 ГБ), пересчитывает аналоги и коммитит `data/scenarios/*.json` вместе с обновлённым `data/manifest.json`. Новые сценарии сами появятся в выпадающем списке **Scenario**.

Локальный запуск:

```bash
pip install numpy scipy rasterio
python pipeline/build_cmip6.py --ssps 245 585 --periods 2041-2060 2061-2080
```

## Структура

```
index.html, assets/          фронтенд (Leaflet 1.9.4 вложен в репозиторий, внешние CDN не нужны)
data/cities.json             517 городов: координаты и названия (Natural Earth)
data/manifest.json           список сценариев
data/scenarios/*.json        PC-координаты, топ-5 аналогов, флаг нового климата
data/countries.json       контуры стран (подложка без интернета)
pipeline/build_bastin.py     матрица Bastin → развёртывание → JSON
pipeline/build_cmip6.py      WorldClim + CMIP6 → PCA → аналоги → JSON
.github/workflows/           сборка CMIP6-сценариев
```

### Формат сценария

```jsonc
{
  "id": "...", "label": {"ru": "...", "en": "..."}, "horizon": "2050", "scenario": "RCP4.5",
  "pc_share": [..],                 // доли дисперсии компонент
  "cur": [[pc1..pcK] | null],       // сегодняшний климат города i
  "fut": [[pc1..pcK] | null],       // будущий климат города i
  "self": [d | null],               // расстояние между настоящим и будущим климатом города
  "novel": [bool | null],           // вне выпуклой оболочки
  "top": [[[j, d] x5] | null],      // ближайшие сегодняшние города
  "vars": {"cur": {"bio1": [..]}, "fut": {...}}   // только CMIP6
}
```

## Функции интерфейса

- Режим **City's future** («Будущее города») показывает дугу к аналогу, пять ближайших аналогов, сдвиг в км и направление.
- Режим **Who becomes like it** («Кто станет похож») показывает города, чей будущий климат ближе всего к сегодняшнему климату выбранного города.
- Мини-график климатического пространства PC1 × PC2: сдвиг города и положение аналогов.
- Цвет точки показывает, насколько изменится климат города. Пунктирное кольцо означает новый климат.
- Слой **Show all shifts** («все переходы»), поиск по названию города или страны, ссылки на город вида `#c=Moscow&s=...&m=reverse`.

## Ограничения

Аналог подбирается только по климату. Рельеф, близость моря и городской остров тепла не учитываются. Значения берутся в одной точке, в центре города. Модели и сценарии расходятся между собой. Для нового климата аналог приблизителен.
